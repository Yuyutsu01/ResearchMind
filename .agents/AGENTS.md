# ResearchMind Customizations & Rules

This document outlines workspace-level behaviors and constraints for AI pair programmers.

---

## Documentation Style constraints

* **Strictly Professional Tone**: Do not include emojis, logos, or casual symbols (e.g. 🔬, 🏗️, 🛠️, 🚀) inside README.md, technical guides, or API specifications.
* **Comment Logic**: Maintain clear comments detailing the intuition behind all PostgreSQL transaction handlers, async scheduling states, and virtualized components.
